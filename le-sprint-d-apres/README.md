# Le Sprint d'après

*Agilité, agents et spécifications : un roman d'entreprise et un manuel pour travailler avec Claude Code et BMAD.*

Une mutuelle lilloise, une équipe réduite et quatorze semaines pour livrer un portail de déclaration de sinistres avec un agent de code. Thomas Leclercq, directeur de projet indépendant, raconte le pari, l'euphorie, la crise, la reconstruction, puis le passage au développement piloté par les spécifications avec la méthode BMAD.

Le livre se lit en deux temps :

- **Partie I, le roman** : 27 chapitres et un épilogue. Chaque chapitre se termine par *Le carnet de Thomas* : ce qui s'est passé, la leçon, trois questions à poser à son équipe, et un renvoi vers le manuel.
- **Partie II, le manuel de référence** : 14 chapitres pour installer, configurer et utiliser Claude Code et BMAD, suivis de 6 annexes pratiques.

> Version de travail. Les fichiers sont des exports Markdown des manuscrits ; les schémas interactifs n'y sont pas reproduits et sont signalés à leur emplacement.
